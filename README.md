# Meu Primeiro Repositório

Este é um repositório de exemplo criado para o **Minicurso de Git e GitHub**.

O objetivo é aprender a utilizar o Git, trabalhar com branches e conhecer as funcionalidades do GitHub.

## Conteúdos do Minicurso

- Introdução ao Git e GitHub
- Criação de repositórios
- Commits e histórico de alterações
- Criação e gerenciamento de branches
- Merge e resolução de conflitos
- Push e Pull

## Comandos Básicos

Alguns comandos importantes do Git:

```bash
git init
git add .
git commit -m "Meu primeiro commit"
git push origin main
```

## Exemplo de Tabela

| Comando | Descrição |
|---------|-----------|
| `git status` | Verifica o estado do repositório |
| `git add` | Adiciona arquivos à área de preparação |
| `git commit` | Registra as alterações |
| `git push` | Envia alterações ao repositório remoto |
| `git pull` | Atualiza o repositório local |
